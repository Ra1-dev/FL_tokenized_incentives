## Exact choices and expected effects

The paper does not fully specify the layer layout, image normalization, partition rounding, minimum client size, minibatch order or random-number streams. This repository fixes them in the configuration and source. Those choices affect convergence and therefore cosine magnitudes and reward shares; matching the same seed label does not imply matching the original random sequence.

The model uses unpadded convolutions, ReLU and max pooling. The final logits are trained with cross entropy and fresh SGD each round. Updates are local parameters minus the starting snapshot, converted to float64 before subtraction. The next global parameters are the starting model plus the sample-count-weighted mean update, rounded to the model's float32 dtype. Every sampled adversary participates in this aggregation.

Quality uses the unweighted mean of the sampled updates, with self-inclusion. Rewards are normalized over sampled clients. The equal-stake dilution in the published standard contract multiplies payouts by a constant and therefore does not change the fraction captured by attackers in this fixed-size experiment. The source's prose and dilution equation are not fully consistent; we reproduce normalized attacker shares, not absolute diluted token totals.

A stale client trains from the saved global snapshot at the lagged source round, using that source round's local shuffle seed. It reports the resulting delta relative to that old snapshot. It does not substitute an arbitrary previous participation or subtract today's global parameters. Label flipping reverses the label order. Zero, noise and sign replacements are applied by the coordinator after local training.

Sampling and local training use independent coordinate-seeded random streams. Reply arrival order never affects the order of scientific clients. All registered reward rules receive the same read-only matrix, whose hash is logged. The scorer cannot affect the training model. Multi-Krum receives the true configured attacker fraction, which favors that baseline; its accepted-set size is explicitly the sampled count minus its fault budget.

CPU runs use deterministic Torch algorithms and a fixed thread count. Repeatability is tested on byte hashes of per_round.csv and round_metrics.csv; timing and transport addresses are excluded. CPU and GPU need not be bit identical. Before full runs, the cross-device comparison tolerance is set to two percentage points in final accuracy; raw score differences will also be reported, never silently treated as identical.

The installed Flower Python simulation entry point is deprecated but still invokes its official Ray simulation runtime, ServerApp and ClientApp Message API. It is used to make the requested Python command self-contained. No substitute training loop or synthetic transport generates reported FL results. Flower runtime dependency installation and telemetry are disabled by the runner. The configuration records worker count and GPU fraction.

The current integer ledger uses the literal prescribed floating-share conversion. Floating representation can produce a tiny negative remainder; it is exposed rather than hidden. Contract settlement is not yet claimed complete. A conservative conversion policy must be resolved before contract measurements.

## Run

```bash
python scripts/download_data.py --dataset mnist
python scripts/run_experiment.py --config configs/smoke.yaml --seed 100 --device cpu
python scripts/run_experiment.py --config configs/sendros_mix.yaml --seed 42 --device cpu
python scripts/reproduce_sendros.py --device cpu
```

Download is separate from training. Tests and experiments do not access the network for data. The runner overwrites its named result files on rerun; use --output to preserve an independent repeat. Resolved metadata records library versions, source commit, device, status and runtime. Reduced smoke configurations are explicitly marked and cannot be used as full reproduction evidence.

## Source inconsistencies and limits

- Table 3 caption claims residual below three percent for every listed measurement; rounded row values and match percentages are not fully consistent with that caption.
- The table labels a ratio of standard deviations as a variance multiplier. Reproduction will distinguish these quantities.
- Equation 1 at equal unit stakes and zero quality for absent clients dilutes total payout by the registered count; the adjacent prose instead says pool/K. The constant factor cancels in within-run attacker share when N and K remain fixed.

No exact-match claim is made for the source's crossover round or aggregate reward share. The reproduction analysis retains every noise-adversary participation, including large residuals, and reports both sample and population standard deviations. The protocol is fixed before observing full evaluation runs.
