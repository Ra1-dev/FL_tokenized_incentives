# Parameter sensitivity of the proposed rule

Generated by `python scripts/sensitivity_assets.py` from `results/sensitivity_sweep/summary.json`.

## What was replayed

Mstar computes one leave-one-out median quality per participation; reputation, the low-quality threshold and penalties act only on those recorded qualities, and the shared global model never depends on rewards. `python scripts/sensitivity_sweep.py` therefore replays 120 settings over the 17 main-horizon scenarios and 5 seeds of the recorded grid without retraining: beta in [0.0, 0.5, 0.7, 0.8, 0.9, 0.95, 0.99], threshold in [0.0, 0.05, 0.1, 0.2] and patience in [1, 2, 3, 5] with penalties, every beta without penalties, and the reference alone. Before any other setting is scored, the frozen setting must reproduce every recorded share and slash and the published pooled estimates exactly; the script stops otherwise.

Pooling and intervals follow the published comparison: scenarios are averaged within each seed and whole seeds are resampled. Attacker share pools attacked scenarios; the honest low-reward rate also includes attack-free runs.

## Findings

- No setting lowers the honest low-reward rate below 14.49%, the value of the reference alone (5.36% attacker share). Reputation and penalties can only trade along a narrow frontier: attacker share ranges from 4.13% (at 67.50% honest cost) to 5.55%.
- The frozen setting (5.16%, 15.23%) lies just inside it; the best dominating setting lowers honest cost by only 0.23 percentage points. The honest cost is set by the leave-one-out median reference, not by the selected parameters.
- With a zero threshold, every penalty setting matches reputation without penalties at the same beta on both pooled metrics: a participation slashed for zero quality already earns nothing. This agrees with the identical Aema and Afull ablation outcomes; the slash events still burn stake in settlement.
- CGSV (7.95%, 4.48%) and RFFL (7.20%, 4.55%) lie outside the region any Mstar setting reaches: lower honest cost at a higher attacker share.

## Scope

This is an exploratory, post-hoc replay on the evaluation grid itself. The frozen parameters were selected earlier on disjoint pilot seeds ([method](METHOD.md)); no setting here replaces them, and choosing the best-looking setting from this table would be optimistic. Only parameters that act after the reference were varied; the reference construction and the initial reputation are unchanged.
